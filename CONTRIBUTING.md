# Contributing to ZhThesis

Thank you for using ZhThesis and for considering an improvement to the project.
Reports from real thesis workflows help make the class more reliable across
LaTeX distributions and institutional requirements.

## Issues

Open an issue for:

- reproducible compilation or layout problems;
- documentation corrections;
- compatibility reports;
- accessibility or typography concerns; or
- focused feature proposals.

Include the operating system, TeX distribution, XeLaTeX version, relevant log
output, and a minimal example when possible. Remove personal, academic, and
institutionally sensitive information before sharing files or logs.

Institution-specific requirements vary. Please link to an authoritative public
formatting guide when proposing a rule tied to a university or degree program.

## Pull Requests

For a substantial change, open an issue first so the scope and compatibility
impact can be discussed. Keep pull requests focused, identify user-visible
changes, and update documentation or examples when appropriate.

By submitting a contribution, you agree that it may be distributed under the
repository's LaTeX Project Public License terms.

## Community

Constructive questions and thoughtful improvements are welcome. Thank you for
using the project, sharing your experience, and recognizing the work involved in
maintaining a dependable thesis framework.
